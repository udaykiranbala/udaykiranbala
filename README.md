These are project directions I've been developing or exploring. Repository links can be added once the corresponding public repositories are verified.

<details>
<summary><b>🤖 FRIDAY — Personal AI Assistant</b></summary>

A Jarvis/FRIDAY-inspired assistant interface combining conversational AI, voice interaction, and desktop-oriented utilities.

**Technical areas:** Python, React/Vite, API integration, speech synthesis and recording, local model experimentation, and service diagnostics.

**Engineering focus:** Keep the existing UI stable while improving reliability, modularity, model routing, and voice interaction.

</details>

<details>
<summary><b>🛡️ FaceGuard — Face-Based Access Prototype</b></summary>

A desktop security prototype exploring face detection and face matching as part of a local access workflow.

**Technical areas:** Python, Tkinter, OpenCV, YuNet, SFace, and local authorization data.

**Engineering focus:** Registration and matching flows, threshold testing, clear locked/unlocked states, and dependable error handling.

> Experimental prototype only; face matching should not be treated as a complete security system without additional safeguards and evaluation.

</details>

<details>
<summary><b>🧠 NLP & AI Chatbot Experiments</b></summary>

A learning track for understanding how conversational applications connect user input, application logic, model inference, and responses.

**Technical areas:** Python, Flask, API design, Hugging Face model exploration, local LLMs, NLP, and introductory deep-learning concepts.

**Engineering focus:** Input validation, clean request/response handling, model integration, and understanding the pipeline rather than treating it as a black box.

</details>

<details>
<summary><b>🚗 3D Open-World Driving Prototype</b></summary>

A browser-based driving-world experiment with procedural scenery, vehicle controls, traffic, camera modes, and a human-mode concept.

**Technical areas:** HTML, JavaScript, 3D scene logic, procedural world generation, collision handling, vehicle movement, and UI state.

**Engineering focus:** Road geometry and collisions first, then physics, interaction reliability, performance, and world detail.

</details>

<details>
<summary><b>🎓 Student Management System</b></summary>

A student-focused database application exploring the connection between application logic and relational data.

**Technical areas:** Python and MySQL.

**Engineering focus:** CRUD operations, schema design, input validation, and predictable database interactions.

</details>
